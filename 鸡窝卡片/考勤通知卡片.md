# 考勤异常钉钉通知卡片

## 字段

| 字段 | 说明 | 示例 |
|---|---|---|
| 员工名字 | 异常员工姓名 | 张三 |
| 日期 | 考勤异常日期 | 2026-07-20（周一） |
| 提醒 | 固定文案 | 在 9:30 前未提交有效拜访记录 |
| 本月正常考勤天数 | 当月正常出勤累计 | 12 天 |
| 异常考勤天数 | 当月异常出勤累计 | 3 天 |
| 正常出勤率 | 正常天数 /（正常+异常） | 80.0% |

## 卡片结构

1. **标题区**：考勤异常提醒
2. **信息行**（label 左 / value 右）：员工名字、日期、提醒、本月正常考勤天数、异常考勤天数、正常出勤率
3. **无操作区**：不提供按钮、不提供行内链接
