# 数据查询（管理端）· 数据需求

> 依据原型：`数据查询_管理端.html`  
> 本文档仅描述数据逻辑，不含其他功能模块说明。

## 3.3 数据需求

| 页面 | 逻辑 |
| ---- | ---- |
| 巡场报告查询 | **数据范围**：巡场报告主表（含客户、技术老师、创建日期、拜访次数、拜访方式、异常维度数、未解决数、是否发送客户群、关联工单编号）。**筛选**：创建日期起止（闭区间，按报告创建日期落在区间内）；技术老师精确匹配；客户名称模糊包含；发送状态=已发送客户群 / 未发送 / 全部。点击「查询」后刷新统计与明细，「重置」恢复默认筛选条件。**顶部统计（基于当前筛选结果）**：报告总数；已发送客户群数及发送率（已发送/总数，百分比四舍五入）；涉及老师数（技术老师去重）。**明细字段**：报告编号、客户、技术老师、创建日期（列表展示可为汇报/创建日期）、拜访次数（展示为「第N次」）、拜访方式、异常维度数、未解决数、是否有效（有效/无效；无效时展示无效原因）、发送客户群（已发送/未发送）、关联工单（无则「—」）。**操作**：查看详情 → 跳转 PC 巡场报告详情页，携带报告编号。**分页**：每页 10 条。**导出**：导出当前筛选结果 CSV，字段与明细一致（不含操作列）。 |
| 诊断工单查询 | **数据范围**：诊断工单主表（客户、业务员、技术老师、需求类型、提交时间、是否已诊断、拜访时间、反馈结果、确认人、确认时间）。**筛选**：提交时间起止（按提交日期落在区间内）；技术老师精确匹配；客户名称模糊包含；诊断状态=未诊断/已诊断/全部；反馈状态=待反馈/已解决/未解决/全部。其中「待反馈」=已诊断且尚未确认反馈；「已解决/未解决」按业务员确认结果匹配。**顶部统计（基于当前筛选结果）**：工单总数；已诊断数及占比；待反馈数（已诊断未反馈）；已解决数。**反馈状态展示**：未诊断展示「—」；已诊断且未确认=待反馈；确认已解决=已解决；确认未解决=未解决。**反馈时长**：有拜访时间且有确认时间时，`反馈时长（小时）= round((确认时间 − 拜访时间) / 1小时)`；缺任一时间或确认时间早于拜访时间则展示「—」。**操作**：按工单编号反查关联巡场报告；有关联报告时展示「查看巡场报告」并跳转 PC 巡场报告详情（携带报告编号）；无关联报告展示「—」。**分页**：每页 10 条。**导出**：导出当前筛选结果 CSV，含反馈时长、巡场报告编号等明细字段。 |
| 技术老师工作体现 | **数据范围**：在提交时间区间内，汇总巡场报告 + 诊断工单，按技术老师聚合；可选按技术老师筛选。报告侧按报告创建日期落入区间；工单侧按提交日期落入区间。**顶部统计（基于当前筛选汇总）**：老师人数；巡场报告合计；主动拜访报告数（报告无关联工单）；平均工单解决率（各老师解决率算术平均，百分比四舍五入）。**明细指标口径**：① 巡场报告数=该老师筛选期内报告条数；② 已发送客户群=筛选期内已发送报告数，旁注发送率=已发送/报告数；③ 有效拜访量=筛选期内是否有效=有效的报告数；④ 主动拜访=报告无关联工单；⑤ 工单诊断=报告有关联工单；⑥ 覆盖客户数=报告客户与工单客户并集去重；⑦ 实地拜访/电话拜访=按报告拜访方式计数；⑧ 已诊断工单/未诊断工单=筛选期内工单按是否完成诊断计数；⑨ 工单解决率=已解决工单数 / 已诊断工单数（已诊断为 0 时为 0%）；⑩ 待反馈工单=已诊断且未确认反馈的工单数。**导出**：导出当前汇总表全部指标列。 |
