# 【需求】业务端 · 客户档案 · 白条档案

> **原型**：`业务端_客户档案_白条档案.html`  
> **范围**：客户档案内「白条档案」Tab 摘要卡、四类资料补件入口、底栏【查看详情】及详情全貌。机会点 / 交易配置 / 地址管理 / 银行资质仅作壳层示意，**本期不改**。  
> **演示态（原型顶栏，非线上 UI）**：未申请白条 / 已申请·资料齐全 / 已申请·资料缺失 / 已申请·驳回 / 查看详情。

---

## 1. 页面结构

| 区域 | 说明 |
| --- | --- |
| 导航 | 「客户档案」；返回 ‹ |
| 横向 Tab | 机会点、交易配置、地址管理、银行资质、**白条档案**（本期） |
| 白条档案面板 | 未申请空态 **或** 白条档案摘要卡 |
| 底栏 | 白条档案已申请时：【查看详情】；银行资质 Tab：【编辑】（示意）；其他 Tab 隐藏底栏 |
| 查看详情页 | 全屏二级页；返回回白条档案 Tab |

## 2. 白条档案 Tab

| 页面 | 逻辑 |
| --- | --- |
| **白条档案（摘要）**<br/><br/>状态：未申请 / 已申请·资料齐全 / 已申请·资料缺失 / 已申请·驳回<br/><br/>卡片「白条档案」字段自上而下：<br/>客户姓名<br/>白条开通状态<br/>驳回原因（仅有驳回时）<br/>上银白条启用状态<br/>上银可用额度<br/>锡商白条启用状态<br/>锡商可用额度<br/>平台最高可用额度<br/>当前可用额度<br/>购买品类<br/>初审资料 · 齐全度 + 操作<br/>正式进件资料 · 齐全度 + 操作<br/>业务员尽调资料 · 齐全度 + 操作<br/>担保资料 · 齐全度 + 操作<br/><br/>底栏【查看详情】 | **1. 入口**<br/>业务端打开某客户「客户档案」→「白条档案」。无客户权限不可进。<br/><br/>**2. 未申请**<br/>空态文案「客户未申请白条」；不展示摘要卡与底栏【查看详情】。<br/><br/>**3. 摘要字段**<br/>已申请时展示卡片。开通状态字色：通过类绿（如白条已开通）、进行中橙（如正式进件审核中）、驳回类红（如初审驳回）。无值显示 —。<br/>驳回原因：仅驳回类状态展示整行；无驳回隐藏。<br/>额度与启用（成对展示）：上银白条启用状态 + 上银可用额度；锡商白条启用状态 + 锡商可用额度；其后为平台最高可用额度、当前可用额度、购买品类；无值 —。<br/><br/>**演示示例**<br/>· 资料齐全：白条已开通；上银已启用 / 上银可用 32 万；锡商未启用 / 锡商 —；平台最高 50 万；当前可用 32 万；品类预混料；四类资料齐全。<br/>· 资料缺失：正式进件审核中；启用与额度类多为 — 或平台最高有值；业务员尽调资料缺失 N 项、担保缺失 N 项等。<br/>· 驳回：初审驳回；展示驳回原因；启用/额度多为 —；后续阶段资料可为 —。<br/><br/>**4. 四类资料行**<br/>取值：齐全 / 缺失 N 项（N≥1）/ —（阶段未开始）。字色：齐全绿、缺失红、— 默认。<br/>右侧按钮：<br/>· 缺失… →【去补齐】<br/>· 齐全 →【修改资料】<br/>· — →【去补充】<br/>跳转（带档案来源，便于返回本 Tab）：<br/>· 初审资料 → 客户端初审资料上传<br/>· 正式进件资料 → 客户端正式进件资料补充<br/>· 业务员尽调资料 → `业务端_申请资料填写.html`（见《【需求】业务端申请资料填写》）<br/>· 担保资料 → 客户端担保人补充资料<br/><br/>**5. 底栏**<br/>已申请：【查看详情】进详情页。未申请：隐藏底栏。本页无审批、不发消息。补件成功后回本 Tab 刷新齐全度与摘要。<br/><br/>**6. 数据字段（读）**<br/>客户姓名、开通状态、驳回原因、上银白条启用状态、上银可用额度、锡商白条启用状态、锡商可用额度、平台最高可用额度、当前可用额度、购买品类、初审/正式进件/业务员尽调资料/担保齐全度、工单 id。本页不落库。 |

## 3. 查看详情

| 页面 | 逻辑 |
| --- | --- |
| **查看详情**<br/><br/>入口：底栏【查看详情】（或原型演示「查看详情」）<br/>导航「查看 · {客户姓名}」；返回回白条档案 Tab<br/><br/>卡片自上而下：<br/>① 资料与 AI 识别<br/>② 平台客户信息<br/>③ 融资主体信息<br/>④ 初审附件<br/>⑤ 客户正式进件资料<br/>⑥ 业务员尽调资料<br/>⑦ 征信信息<br/>⑧ 交易信息<br/>⑨ 推送银行<br/>⑩ 操作日志 | **1. 入口**<br/>仅已申请可进；未申请提示暂无详情。返回关闭详情，回到白条档案。<br/><br/>**2. 资料与 AI 识别**<br/>初审资料齐全度；非纯初审阶段增加客户正式进件、业务员尽调资料齐全度；AI 结果与说明、门槛提示。驳回时增加驳回原因块。<br/><br/>**3. 平台客户信息**<br/>手机号、客户姓名、业务员、平台审核状态。<br/><br/>**4. 融资主体信息**<br/>融资主体名称、法人手机号、全价料白条、进件门槛文案。<br/><br/>**5. 初审附件**<br/>网格：营业执照、法人身份证正/反面、法人征信报告；已上传高亮。<br/><br/>**6. 客户正式进件资料**<br/>有数据：状态、额度档位、产品类型、是否全价料、流水来源与解压密码、附件（邮箱解析流水/百行/实控人征信 + 上传类）。无数据：初审未通过提示不可补件，否则「暂未提交正式进件资料」。<br/><br/>**7. 业务员尽调资料**<br/>有数据：状态、白条产品类型、额度档位、上银/锡商额度、养殖种类与数量、申请原因、现场照片、CRM 拜访。无数据：「暂未提交业务员尽调资料」。<br/><br/>**8. 征信信息**<br/>逾期笔数、不良贷款笔数、已结清贷款笔数。<br/><br/>**9. 交易信息**<br/>近 6 月累计交易月数、月均交易吨数、月均交易金额（元）。<br/><br/>**10. 推送银行**<br/>上海银行、锡商银行：额度金额、推送状态、审批结果标签。<br/><br/>**11. 操作日志**<br/>时间轴（已完成 / 当前）；无则「暂无操作记录」。<br/><br/>**12. 边界**<br/>只读；不编辑、无审批、不发消息。 |

## 4. 与二期关系

- 业务员尽调资料行的【去补齐】/【修改资料】/【去补充】进入二期「业务端申请资料填写」页（业务员尽调资料）。  
- 客户正式进件、Admin 审核不在本文展开。
