# 金融白条申请线上化 — 流程与页面功能

> 依据 `mrd金融白条申请.md` + 流程图整理。步骤4（启用审核、标签配置、额度激活）已有能力，不在本次开发范围。

---

## 一、角色


| 角色   | 端     | 职责                          |
| ---- | ----- | --------------------------- |
| 业务员  | CRM   | 收集/上传资料、发起初审与正式进件、补担保人、查看进度 |
| 金融审核 | admin | 初审/正式进件/担保人资料审核；推送银行；消息触达   |
| 客户   | 银行APP | 上银路径需客户在银行APP自行申请（系统侧发消息引导） |
| 银行   | 外部    | 审批；结果回传后系统通知金融与业务员          |


合作银行路径差异：

- **锡商**：正式进件审核通过后，资料接口直连银行 → 进入银行审批
- **上银**：正式进件审核通过后，消息通知业务员+客户 → 客户上银APP申请 → 银行审批

---

## 二、主流程（状态机）

```
初审资料提交
  → 金融初审
      ├─ 驳回 → 业务员补资料重提
      └─ 通过（含资料不全需补正式资料）
          → 正式进件（补流水/许可证/资产等）
              → 金融正式审批
                  ├─ 驳回 → 业务员补正式资料重提
                  └─ 通过
                      ├─ 锡商：推送银行接口
                      └─ 上银：通知业务员+客户 → 客户APP申请
                          → 银行审批
                              └─ 通过 → 通知金融+业务员
                                  → 补充担保人资料
                                      → 金融审批（三方查询留痕）
                                          → 【已有】启用标签/配置参数/额度激活 → 办结
```

建议工单状态：


| 状态    | 说明                |
| ----- | ----------------- |
| 初审待提交 | 业务员未提交            |
| 初审审核中 | 已提交，待金融           |
| 初审已驳回 | 需按原因补齐重提          |
| 初审通过 | 初审通过，待补正式资料 |
| 正式进件审核中 | 正式资料已提交，金融审核中 |
| 进件资料审核通过 | 正式审核通过；展示合作银行（锡商/上银）、申请额度；操作「申请白条」 |
| 正式已驳回 / 进件资料被驳回 | 正式资料被驳回，需重新补充进件资料 |
| 银行审核中 | 等待银行审批结果；展示合作银行（锡商/上银） |
| 银行审核通过 | 银行通过；后续补担保人/启用走已有流程（不单独设「待补担保人」状态） |
| 担保审核中 | 担保资料已提交待金融 |
| 待开启配置 | 银行通过后进入已有开启配置流程；展示合作银行、额度（本需求不新开发开启配置） |
| 已办结 | 额度启用完成；展示合作银行、金额 |
| 禁用 | 额度已禁用；展示合作银行、金额 |

| 审核待办列表 | 初审/正式/担保人三类；筛选状态、产品模板、额度档 | P0 |
| 初审审核页 | 查看证件；展示邮箱征信/百行接收状态与风控结果；通过/驳回 | P0 |
| 正式进件审核页 | 待审核：通过/拒绝；**审核通过**：查看、编辑、推送银行；**审核拒绝**：查看、编辑；支持按状态筛选 | P0 |
| 担保人资料审核页 | 待审核：通过/驳回；**审核通过** / **审核驳回**：查看、编辑 | P0 |




### 消息卡片（系统通知）


| 触发点      | 接收人    | 内容要点                   |
| -------- | ------ | ---------------------- |
| 初审通过/驳回  | 业务员    | 客户名、结果、驳回原因、跳转补资料或正式进件 |
| 正式通过（上银） | 业务员+客户 | 引导客户打开上银APP申请          |
| 正式通过（锡商） | 业务员    | 已推送银行，等待审批             |
| 正式驳回     | 业务员    | 原因 + 跳转正式申请            |
| 银行审批通过   | 金融+业务员 | 提醒补担保人 / 进入后续流程        |
| 催补担保人    | 业务员    | 跳转补充资料页                |
| 担保审核结果   | 业务员    | 通过进入已有启用流程 / 驳回重提      |


### 不在范围

- 启用标签、配置参数、额度激活（步骤4，已有）
- 银行APP内申请页（外部）
