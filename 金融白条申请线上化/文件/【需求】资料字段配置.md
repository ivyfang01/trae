# 【需求】Admin · 资料字段配置

> **范围**：Admin「资料字段配置」本页——维护业务员尽调、客户正式进件两套资料的**字段模块**与**字段**（含按一级选项显隐的关联字段）。不采集填报数据，不渲染真实表单。  
> **原型**：`admin-字段配置.html`  
> **入口**：粮巴巴管理系统 → 白条 → 侧栏「资料字段配置」。  
> **背景**：尽调 / 正式进件字段随产品类型等变化，需可配置「白条产品类型 = 全价料 → 在「饲料信息」展示全价料相关字段」这类规则，减少发版改表单。

## 2. 页面逻辑

### 2.1 配置域

| 配置域 Tab | 用途 | 数据 |
| --- | --- | --- |
| 业务员尽调资料字段配置 | 驱动业务端尽调填写页 | 与正式进件互不共享 |
| 正式进件资料字段配置 | 驱动客户端正式进件补件页 | 同上 |

默认进入「业务员尽调资料字段配置」。切换 Tab 刷新左侧模块与右侧列表。

### 2.2 字段模块（左栏）

| 操作 | 行为 |
| --- | --- |
| 【＋ 模块】 | 弹窗新增：模块名称*、排序 |
| 【编辑】 | 修改名称、排序 |
| 【删】 | 二次确认后删除该模块及其全部字段 |
| 点击模块行 | 选中；右侧展示该模块下的字段列表 |

- 模块按「排序」升序展示（数字越小越靠前）。
- 行上展示字段数量。
- 空态：「暂无模块，请先新增」。

### 2.3 字段列表（右栏）

选中模块后，标题为「{模块名} · 字段列表」。

| 操作 | 行为 |
| --- | --- |
| 【＋ 字段】 | 打开统一字段弹窗（新增）；未选模块时禁用 |
| 【编辑】 | 打开统一字段弹窗 |
| 【上移】/【下移】 | 调整本模块内字段顺序（全部字段均可） |
| 【删除】 | 二次确认；若删的是一级字段，级联删除全配置域内关联到它的字段 |

**列表列**

| 列 | 说明 |
| --- | --- |
| 字段名字 | 字段名称；一级与关联字段同级展示，不缩进 |
| 展示模块 | 本字段所属模块名称（即当前左栏选中模块） |
| 类型 | 文本 / 数字 / 单选 / 多选 / 上传图片 / 上传文件 |
| 关联一级字段 | 未关联：—；已关联：一级字段名称 |
| 关联字段条件 | 未关联：—；已关联：`= {选项值}` |
| 操作 | 编辑、上移、下移、删除（全部行一致） |

空态：「该模块暂无字段，点击右上角「＋ 字段」添加」。

### 2.4 添加 / 编辑字段（统一弹窗）

一套弹窗覆盖「一级字段」与「关联字段」，差异仅在是否选择关联。

| 场景 | 关联区 | 所属模块 | 说明 |
| --- | --- | --- | --- |
| 新增 | 展示 | 可筛选选择 | 默认「不关联」；选关联后须选一级选项值 |
| 编辑 · 一级字段 | 隐藏 | 可改 | 只改字段属性；可迁到其他模块 |
| 编辑 · 关联字段 | 展示 | 可改 | 可改关联一级 / 选项值，或改为不关联升为一级 |

**核心约定**

1. **关联一级字段**下拉为「不关联」+ 可关联的一级字段（尽调示例：白条产品类型、客户类型、是否牧场、养殖类型、白条金额是否大于30万）；选项来自已标记可关联的单选/多选一级字段。
2. **所属模块（展示模块）**与一级字段所在模块**可不同**。典型：一级「白条产品类型」在「白条申请」，关联字段落在「饲料信息」。
3. 填报端：一级选中值 = 关联字段的选项值时展示该字段，否则隐藏。
4. 一级字段格式从单选/多选改为其他类型时：清空其选项，并级联删除全部关联字段。

**本页不做**：真实填报表单渲染、初审资料配置、消息发送。

## 3. 信息结构

### 3.1 字段模块

| 属性 | 必填 | 规则 |
| --- | --- | --- |
| 模块名称 | 是 | 如「白条申请」「饲料信息」；最长 40 字 |
| 排序 | 否 | 数字越小越靠前 |

### 3.2 字段（统一模型）

字段均为模块下的扁平列表项；是否关联由 `关联一级字段` + `一级选项值` 决定。

| 属性 | 必填 | 规则 |
| --- | --- | --- |
| 关联一级字段 | 否 | 不选 = 一级字段；可选配置域内单选/多选一级（须已有选项）；关联字段自身不可再作父级 |
| 一级选项值 | 条件 | 已选关联时必填；下拉取该一级的选项 |
| 字段名称 | 是 | 最长 40 字 |
| 字段格式 | 是 | 文本 / 数字 / 单选 / 多选 / 上传图片 / 上传文件 |
| 选项 | 条件 | 本字段为单选/多选时必填，至少 1 项 |
| 是否必填 | 是 | 是 / 否 |
| 所属模块 | 是 | 可关键字筛选；决定「展示模块」与填报分区；编辑可迁模块 |
| 占位提示 | 否 | — |
| 备注 | 否 | 如保证金提醒文案 |

**存储约定（实现）**：关联字段写 `parentFieldId` + `whenValue`；与一级字段同属所选模块的 `fields[]`，不再嵌套 `children`。

### 3.3 级联与迁移

| 行为 | 说明 |
| --- | --- |
| 删除模块 | 删除该模块下全部字段 |
| 删除一级字段 | 级联删除全配置域内 `parentFieldId` 指向它的关联字段 |
| 删除关联字段 | 仅删本条 |
| 改所属模块 | 字段迁入目标模块，并切换右栏当前模块到目标 |
| 关联字段改「不关联」 | 升为一级，清除 `parentFieldId` / `whenValue` |

## 4. 弹窗字段

### 4.1 新增 / 编辑模块

| 字段 | 必填 |
| --- | --- |
| 模块名称 | 是 |
| 排序 | 否 |

【取消】【确定】。

### 4.2 新增 / 编辑字段

弹窗顺序：

1. **关联一级字段**（新增 / 编辑关联时展示；编辑一级时隐藏）  
   - 选项：`不关联` + 可关联一级字段名称（如白条产品类型、客户类型、是否牧场、养殖类型、白条金额是否大于30万）  
2. **一级选项值***（已选关联时展示）  
3. 字段名称*  
4. 字段格式*  
5. 选项*（本字段为单选/多选时）  
6. 是否必填  
7. **所属模块***（可筛选；关联后仍可改）  
8. 占位提示  
9. 备注  

| 校验 | 提示 |
| --- | --- |
| 未填名称 | 请填写字段名称 |
| 单选/多选无选项 | 请至少配置一个选项 |
| 未选所属模块 | 请选择所属模块 |
| 已关联未选选项值 | 请选择一级选项值 |

## 5. 配置示例

### 5.1 业务员尽调

| 展示模块 | 字段 | 关联一级（所在模块） | 条件 |
| --- | --- | --- | --- |
| 白条申请 | 客户名称、白条产品类型、是否能收取保证金、申请额度、白条金额是否大于30万、上银/锡商额度、申请原因 | — | — |
| 饲料信息 | 每月玉米需求量、预混料商品名称、预混料报价 | 白条产品类型（白条申请） | = 预混料 |
| 饲料信息 | 全价料每月吨数、全价料商品名字、单价、全价料捆绑商品的吨数 | 白条产品类型（白条申请） | = 全价料 |
| 饲料信息 | 每月玉米需求总量、每月豆粕需求总量 | 白条产品类型（白条申请） | = 大宗免息白条 |
| 客户养殖信息 | 客户类型、是否牧场、养殖类型 | — | — |
| 经营信息 | 法人是否为实控人、实控人资产情况、现场照片 | — | — |
| 经营信息 | 实控人身份证人像面 / 国徽面、实控人实名手机号 | 法人是否为实控人（经营信息） | = 否 |

> 「是否能收取保证金」备注可含：30万 ≤ 额度 ＜ 50万至少 5%，≥ 50万至少 10%。  
> 「全价料捆绑商品的吨数」可由系统按「申请额度 × 6 ÷ 最低预混料单价」计算（填报端逻辑，本页仅配置字段）。
