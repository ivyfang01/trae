# 【需求】业务端 · 客户档案 · 白条档案

> **原型**：`业务端_客户档案_白条档案.html`  
> **范围**：客户档案内「白条档案」Tab 摘要卡、四类资料补件入口、底栏【查看详情】入口。详情全貌见《【需求】业务端白条申请查看详情》。机会点 / 交易配置 / 地址管理 / 银行资质仅作壳层示意，**本期不改**。  
> **演示态（原型顶栏，非线上 UI）**：未申请白条 / 已申请·资料齐全 / 已申请·资料缺失 / 已申请·驳回 / 查看详情。

---

## 1. 页面结构

| 区域 | 说明 |
| --- | --- |
| 导航 | 「客户档案」；返回 ‹ |
| 横向 Tab | 机会点、交易配置、地址管理、银行资质、**白条档案**（本期） |
| 白条档案面板 | 未申请空态 **或** 白条档案摘要卡 |
| 底栏 | 白条档案已申请时：【查看详情】；银行资质 Tab：【编辑】（示意）；其他 Tab 隐藏底栏 |
| 查看详情页 | 全屏二级页；返回回白条档案 Tab |

## 2. 白条档案 Tab

| 页面 | 逻辑 |
| --- | --- |
| **白条档案（摘要）**<br/><br/>状态：未申请 / 已申请·资料齐全 / 已申请·资料缺失 / 已申请·驳回<br/><br/>卡片「白条档案」字段自上而下：<br/>客户姓名<br/>平台审核状态<br/>驳回原因（仅有驳回时）<br/>上银白条启用状态<br/>上银可用额度<br/>锡商白条启用状态<br/>锡商可用额度<br/>平台最高可用额度<br/>当前可用额度<br/>购买品类<br/>初审资料 · 已提交/未提交 + 操作<br/>正式进件资料 · 已提交/未提交 + 操作<br/>业务员尽调资料 · 已提交/未提交 + 操作<br/>担保资料 · 已提交/未提交 + 操作<br/><br/>底栏【查看详情】 | **1. 入口**<br/>业务端打开某客户「客户档案」→「白条档案」。无客户权限不可进。<br/><br/>**2. 未申请**<br/>空态文案「客户未申请白条」；不展示摘要卡与底栏【查看详情】。<br/><br/>**3. 摘要字段**<br/>已申请时展示卡片。平台审核状态字色：通过类绿（如正式进件审核通过）、进行中橙（如正式进件审核中）、驳回类红（如初审驳回）。无值显示 —。工单内部阶段为已推送银行 / 银行审批中 / 白条已开通 / 银行拒绝时，本字段统一展示为正式进件审核通过（与查看详情一致）。<br/>驳回原因：仅驳回类状态展示整行；无驳回隐藏。<br/>额度与启用（成对展示）：上银白条启用状态 + 上银可用额度；锡商白条启用状态 + 锡商可用额度；其后为平台最高可用额度、当前可用额度、购买品类；无值 —。<br/><br/>**演示示例**<br/>· 资料齐全：正式进件审核通过；上银已启用 / 上银可用 32 万；锡商未启用 / 锡商 —；平台最高 50 万；当前可用 32 万；品类预混料；四类资料均为已提交。<br/>· 资料缺失：正式进件审核中；启用与额度类多为 — 或平台最高有值；业务员尽调、担保为未提交等。<br/>· 驳回：初审驳回；展示驳回原因；启用/额度多为 —；初审已提交，后续资料未提交。<br/><br/>**4. 四类资料行**<br/>取值：**已提交 / 未提交**。字色：已提交绿、未提交红。<br/>右侧按钮：<br/>· 未提交 →【去补齐】<br/>· 已提交 →【修改资料】<br/>跳转（带档案来源，便于返回本 Tab）：<br/>· 初审资料 → 客户端初审资料上传<br/>· 正式进件资料 → 客户端正式进件资料补充<br/>· 业务员尽调资料 → `业务端_申请资料填写.html`（见《【需求】业务端申请资料填写》）<br/>· 担保资料 → 客户端担保人补充资料；按钮样式为**灰色**（与初审/正式件/尽调蓝色按钮区分）<br/><br/>**5. 底栏**<br/>已申请：【查看详情】进详情页。未申请：隐藏底栏。本页无审批、不发消息。补件成功后回本 Tab 刷新齐全度与摘要。<br/><br/>**6. 数据字段（读）**<br/>客户姓名、平台审核状态、驳回原因、上银白条启用状态、上银可用额度、锡商白条启用状态、锡商可用额度、平台最高可用额度、当前可用额度、购买品类、初审/正式进件/业务员尽调资料/担保齐全度、工单 id。本页不落库。 |

## 3. 查看详情

> 完整字段与模块规则见 **《【需求】业务端白条申请查看详情》**（原型 `业务端_白条申请详情.html`）。

| 项 | 说明 |
| --- | --- |
| 入口 | 底栏【查看详情】；仅已申请可进；未申请不可打开 |
| 导航 | 「查看 · {客户姓名}」；无副标题；返回回白条档案 Tab |
| 边界 | 只读；不编辑、无审批、不发消息；补件仍在本 Tab 四类资料行 |

---

## 4. 与二期关系

- 业务员尽调资料行的【去补齐】/【修改资料】进入二期「业务端申请资料填写」页（业务员尽调资料）。  
- 客户正式进件、Admin 审核不在本文展开。

## 5. 待确认

1. 「当前可用额度」与上银/锡商可用额度、平台最高可用额度的计算口径（取小、加总或平台单独授信）。  
2. 「购买品类」枚举是否与白条产品类型（预混料/全价料）一一对应。  
3. 启用状态取值：未启用 / 已启用 / 禁用 等是否与现网启用审核一致。
