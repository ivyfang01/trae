# 【需求】业务端 · 白条申请 · 查看详情

> **范围**：仅业务端「白条申请」详情的 **查看模式**（只读全貌）。白条档案摘要卡、四类资料补件入口、业务员尽调填写、客户端初审/正式件、Admin 审核**不在本文**。  
> **原型**：`业务端_白条申请详情.html`  
> **入口**：客户档案 · 白条档案 Tab 底栏【查看详情】（见《【需求】业务端客户档案白条档案》）  
> **背景**：业务员 / 业务端人员只读查阅本客户白条进件全貌（平台审核状态、资料与 AI、档案、附件、尽调、正式件、征信交易、银行推送与日志），不在本页改状态、不审批、不发消息。

---

## 1. 页面概览

| 项 | 说明 |
| --- | --- |
| 系统壳 | 全屏二级页（盖住白条档案）；顶栏 ‹ 返回 |
| 标题 | `查看 · {客户姓名}` |
| 副标题 | **无**（不展示客户 ID、银行状态等副标题） |
| 组成 | 顶栏 + 正文模块自上而下滚动 |
| 交互约束 | 全部只读；控件不可编辑；附件仅预览/下载；CRM 拜访记录蓝色可点跳转（实现不在本文） |
| 返回 | 顶栏 ‹ → 关闭详情，回到白条档案 Tab |

## 3. 分模块字段

### 3.1 审核状态

| 展示 | 规则 |
| --- | --- |
| 平台审核状态 | 标签；展示名见 §2.3；**不展示银行状态** |
| 驳回原因 | 仅平台态为初审驳回 / 正式进件审核驳回（含正式审核驳回）且有原因时，在状态下方附灰字「驳回原因：{文案}」 |
| 色块 | 驳回类红；正式进件审核通过（含映射后）绿；其余进行中蓝 |

### 3.2 资料与 AI 识别

| 展示 | 规则 |
| --- | --- |
| 客户初审资料 | 已提交 / 未提交（兼容旧值「齐全」展示为已提交） |
| 客户正式进件资料 | 有正式件数据时展示已提交/未提交；无则「暂未提交」 |
| 业务员尽调资料 | 有尽调数据时展示已提交/未提交；无则「暂未提交」 |
| AI审核结果和建议 | 标签：通过 / 审核中 / — / 拒绝等；可附说明（如影像清晰、主体一致）；可附门槛灰字提示（如「初审已通过，可正式进件」） |

### 3.3 平台客户信息

> 平台档案带入，全部只读。

| 字段 | 说明 |
| --- | --- |
| 主体类型 | 个人 / 企业（必填展示） |
| 手机号 | — |
| 客户姓名 | — |
| 客户类型 | 如养殖户等 |
| 平台注册时间 | 日期 |
| 平台累计注册月份 | 数值 |
| 借款人与平台方关联 | 是 / 否 |
| 业务员 | 跟进人姓名 |

> 平台审核状态仅在 §3.1「审核状态」展示，本模块不重复。

### 3.4 融资主体信息

> 平台主体档案带入，全部只读。

| 字段 | 说明 |
| --- | --- |
| 融资主体名称 | — |
| 企业类型 | 如有限责任公司 / 个体工商户 |
| 企业注册时间 | — |
| 证件类型 | 企业：统一社会信用代码；个人：身份证 |
| 证件编号 | — |
| 法人名称 | — |
| 法人手机号 | — |
| 融资主体联系地址 | 多行 |

### 3.5 附件（三区）

> 面板标题「附件」。已上传可预览/下载；未上传灰色占位。

| 分区 | 附件项 | 规则 |
| --- | --- | --- |
| 初审附件 | 营业执照、法人身份证正面、法人身份证反面、信用分截图、法人征信报告 | 来自客户初审 |
| 业务员尽调资料附件 | 实控人身份证正面、实控人身份证反面；现场照片/视频 | **仅**尽调「法人是否为实控人=否」（或申请人是否为实控人=否）时展示实控人身份证正反面；无尽调时提示「业务员尚未提交尽调资料」或「暂无尽调附件」 |
| 客户正式补件附件 | 经营性流水；百行征信报告（条件）；实控人征信报告（条件）；其他正式件上传类 | 百行：全价料产品时展示；实控人征信：额度 ≥30 万时展示。无正式件：初审未过提示「初审通过后方可补充正式进件资料」，否则「客户尚未提交正式进件资料」 |

### 3.6 业务员尽调资料

> 有数据时标题旁「状态：{已提交/未提交}」。数据来源见《【需求】业务端申请资料填写》。

| 子区 | 字段 |
| --- | --- |
| 空态 | 「暂未提交业务员尽调资料」 |
| 白条申请 | 白条产品类型；预混料/全价料时展示是否能收取保证金；申请额度（万）；上海银行额度（万）；上银额度＞0 时展示上银免息期（天）、是否开通自动支付、最长借款期（月）；锡商银行额度（万）；锡商额度＞0 时展示锡商免息期（天）、最长借款期限（月）；上银额度=0 时展示「不申请上海银行原因」；申请原因 |
| 客户养殖信息 | 养殖种类、养殖数量、从事行业年限 + 尽调模板养殖相关字段 |
| 饲料信息 | 随产品类型的模板字段；无则 — |
| 经营信息 | **法人是否为实控人**（或申请人是否为实控人）；=否时展示 **实控人姓名 / 实控人身份证号 / 实控人手机号**；其余从业年限、住址、资产、车牌、是否有合伙人及合伙人信息等（过滤申请人姓名、手机号、法人名字等与档案重复项） |
| CRM 拜访记录 | 有值：蓝色可点击文案，跳转 CRM 拜访记录详情；无值：— |

### 3.7 客户正式进件资料

> 有数据时标题旁「状态：{已提交/未提交}」。数据来源见《【需求】客户端正式进件资料补充》。

| 字段 / 空态 | 规则 |
| --- | --- |
| 空态 | 初审未过（初审驳回 / 初审中等）：「初审通过后方可补充正式进件资料」；已过未提交：「暂未提交正式进件资料」 |
| 经营性流水来源 | 多选结果拼接（如微信、支付宝、银行） |
| {来源}流水解压密码 | **按已选来源逐条明文展示**客户填写内容（不做脱敏/「已填」占位）；未选来源时展示「未选择流水来源」；未填展示「未填」 |
| （无）实控人表单字段 | 不在本模块展示；实控人征信见附件「客户正式补件附件」 |
