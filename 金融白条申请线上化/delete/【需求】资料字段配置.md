# 【需求】Admin · 资料字段配置

> **范围**：Admin 侧配置 **业务员尽调资料**、**客户正式进件资料** 的字段模块、一级字段，以及挂在单选/多选一级字段下的 **关联二级字段**（按一级选项值控制显隐）。  
> **原型**：`字段配置.html`  
> **入口**：粮巴巴管理系统 → 白条 → 资料字段配置（侧栏）。  
> **背景**：尽调页、正式进件补件页字段随产品类型等变化；需可配置「白条产品类型=全价料 → 展示全价料每月吨数等二级字段」这类关联，减少发版改表单。本页只做配置，不采集填报数据。

## 3. 信息结构

### 3.1 配置域

| 配置域 | 用途 |
| --- | --- |
| 业务员尽调资料 | 驱动业务端尽调填写页 |
| 正式进件资料 | 驱动客户端正式进件补件页 |

### 3.2 字段模块

| 属性 | 必填 | 规则 |
| --- | --- | --- |
| 模块名称 | 是 | 如「白条申请」「经营信息」；最长 40 字 |
| 排序 | 否 | 数字越小越靠前 |

> 删除模块：二次确认后删除该模块及其全部一级字段与关联二级字段。

### 3.3 一级字段

| 属性 | 必填 | 规则 |
| --- | --- | --- |
| 字段名称 | 是 | 最长 40 字 |
| 字段格式 | 是 | 文本 / 数字 / 单选 / 多选 / 上传图片 / 上传文件 |
| 选项 | 条件 | 单选、多选必填，至少 1 项；每行一个选项文案 |
| 是否必填 | 是 | 是 / 否 |
| 所属模块 | 是 | **可筛选选择**（输入关键字过滤模块列表）；位于是否必填下方；编辑时可改到其他模块（字段迁入目标模块，并切换右侧当前模块） |
| 占位提示 | 否 | — |
| 备注 | 否 | 说明文案（如保证金提醒文案可写在备注） |

> 一级字段由单选/多选改为其他格式时：清空其选项，并清空全部关联二级字段。

### 3.4 关联二级字段（挂在一级单选/多选的 `children` 下）

| 属性 | 必填 | 规则 |
| --- | --- | --- |
| 一级字段 | — | 只读，当前挂载的父字段 |
| 当一级选项等于 | 是 | 下拉取一级字段已配置选项；对应存储字段 `whenValue` |
| 字段名称 | 是 | 同一级字段 |
| 字段格式 | 是 | 同一级字段 |
| 选项 | 条件 | 二级字段自身为单选/多选时必填 |
| 是否必填 | 是 | 是 / 否 |
| 所属模块 | — | 展示一级字段所在模块，**不可单独修改**（只读） |
| 占位提示 / 备注 | 否 | — |

| 行为 | 说明 |
| --- | --- |
| 同一一级下可挂多条二级字段 | 可对应同一选项多字段，或不同选项各挂字段 |
| 删除一级字段 | 级联删除其全部二级字段 |
| 删除二级字段 | 仅删该条，二次确认 |
| 填报端约定 | 一级选中值 = `whenValue` 时展示；未命中则隐藏 |

### 3.5 字段列表列

| 列 | 说明 |
| --- | --- |
| 字段 | 一级字段名；二级行缩进展示二级字段名 |
| 类型 | 字段格式标签 |
| 必填 | 是 / 否 |
| 展示条件 | **仅展示条件**：一级行固定「—」；二级行仅展示 `当「一级字段名」= 值 时展示`，**不**附带选项、占位、备注等其它信息 |
| 操作 | 一级：编辑、+关联二级字段（仅单选/多选）、上移、下移、删除；二级：编辑、删除（二级不上移下移） |

## 4. 弹窗

### 4.1 新增 / 编辑模块

模块名称*、排序；【取消】【确定】。

### 4.2 新增 / 编辑一级字段

弹窗字段顺序：

1. 字段名称*  
2. 字段格式*  
3. 选项*（仅单选/多选时展示）  
4. 是否必填  
5. **所属模块***（可输入关键字筛选并点选；编辑时可改模块）  
6. 占位提示  
7. 备注  

校验：未填名称、单选/多选无选项、未选择所属模块时拦截。

### 4.3 添加 / 编辑关联二级字段

与 §4.2 **共用同一字段弹窗**；标题为「添加关联字段」/「编辑关联字段」。在名称之前额外展示：

| 项 | 说明 |
| --- | --- |
| 一级字段 | 只读 |
| 当一级选项等于* | 下拉，选项来自一级字段；提示：填报端仅在一级字段选中该值时展示本关联字段 |
| 其后 | 字段名称 / 格式 / 选项 / 必填 / 所属模块（只读）/ 占位 / 备注，同 §4.2 |

> 二级行【编辑】即打开本弹窗编辑该二级字段定义。

校验：未选一级选项值、未填名称、二级自身为单选/多选但无选项时拦截。

## 5. 示例

### 5.1 尽调

| 模块 | 一级字段 | 当选项等于 | 关联二级字段示例 |

## 6. 空态与校验

| 场景 | 表现 |
| --- | --- |
| 无模块 | 左侧空态「暂无模块，请先新增」 |
| 未选模块 | 右侧「请先选择或新建字段模块」；【＋ 字段】禁用 |
| 模块下无字段 | 「该模块暂无字段，点击右上角「＋ 字段」添加」 |
| 非单选/多选点关联二级 | 提示仅单选/多选可添加 |
| 一级无选项时点关联二级 | 提示先为一级字段配置选项 |
| 所属模块筛选无匹配 | 下拉「无匹配模块」 |
| 删除 | 二次确认 |
