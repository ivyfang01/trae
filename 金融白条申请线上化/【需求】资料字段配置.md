# 【需求】Admin · 资料字段配置

> **范围**：Admin 侧配置 **业务员尽调资料**、**客户正式进件资料** 的字段模块、字段定义，以及一级单选/多选下的 **关联字段**（按一级选项值显隐的子字段）。  
> **原型**：`字段配置.html`  
> **入口**：粮巴巴管理系统 → 白条 → 资料字段配置（侧栏）。  
> **背景**：尽调页、正式进件补件页字段随产品类型等变化；需可配置「白条产品类型=全价料 → 展示全价料每月吨数等字段」这类关联，减少发版改表单。本页只做配置，不采集填报数据。

---

| 项 | 说明 |
| --- | --- |
| 系统壳 | 与金融白条审核台一致：顶栏 + 侧栏 + 页签 + 内容区 |
| 标题 | 资料字段配置 |
| 副标题 | 配置模块与字段；单选/多选可通过【+关联二级字段】按选项添加二级字段 |

| 权限 | 仅配置权限角色可进 |

## 2. 页面逻辑

| 页面 | 逻辑 |
| --- | --- |
| **资料字段配置**<br/><br/>原型：`字段配置.html` | **1. 入口**<br/>侧栏进入；默认「业务员尽调资料字段配置」。<br/><br/>**2. 配置域**<br/>尽调 / 正式进件两个 Tab，数据互不共享。<br/><br/>**3. 模块**<br/>左侧维护模块（名称、排序）。<br/><br/>**4. 一级字段**<br/>右侧维护当前模块下的一级字段。【＋ 字段】【编辑】【上移】【下移】【删除】。<br/><br/>**5. 关联二级字段**<br/>仅当一级字段为**单选 / 多选**时，行操作出现【+关联二级字段】。<br/>点击后打开「添加关联字段」：配置 **当一级选项等于某值** + **字段名称、字段格式、必填、选项等**（与新增一级字段相同，只是多了展示条件）。<br/>列表中二级字段以缩进行挂在一级字段下方；行操作【编辑】【删除】即编辑/删除该二级字段定义。<br/>填报端：仅当一级字段选中对应选项时展示该二级字段。<br/><br/>**6. 本页不做**<br/>不渲染真实填报表单；不配置初审资料；不发消息。 |

## 3. 信息结构

### 3.1 配置域

| 配置域 | 用途 |
| --- | --- |
| 业务员尽调资料 | 驱动业务端尽调填写页 |
| 正式进件资料 | 驱动客户端正式进件补件页 |

### 3.2 字段模块

| 属性 | 必填 | 规则 |
| --- | --- | --- |
| 模块名称 | 是 | 如「白条申请」「经营信息」 |
| 排序 | 否 | 数字越小越靠前 |

### 3.3 一级字段

| 属性 | 必填 | 规则 |
| --- | --- | --- |
| 所属模块 | 是 | 可筛选选择；编辑时可改模块（字段迁入目标模块） |
| 字段名称 | 是 | 最长 40 字 |
| 字段格式 | 是 | 文本 / 数字 / 单选 / 多选 / 上传图片 / 上传文件 |
| 选项 | 条件 | 单选、多选必填，至少 1 项 |
| 是否必填 | 是 | 是 / 否 |
| 占位提示 | 否 | — |
| 备注 | 否 | 说明文案 |

### 3.4 关联字段（挂在一级单选/多选下）

| 属性 | 必填 | 规则 |
| --- | --- | --- |
| 一级字段 | — | 只读 |
| 当一级选项等于 | 是 | 取一级字段已配置的选项 |
| 字段名称 | 是 | 同一级字段 |
| 字段格式 | 是 | 同一级字段 |
| 选项 | 条件 | 关联字段自身为单选/多选时必填 |
| 是否必填 | 是 | 是 / 否 |
| 占位提示 / 备注 | 否 | — |

| 行为 | 说明 |
| --- | --- |
| 删除一级字段 | 级联删除其全部关联字段 |
| 填报端约定 | 一级选中 `whenValue` 时展示该关联字段；未命中则隐藏 |

### 3.5 字段列表列

| 列 | 说明 |
| --- | --- |
| 字段 | 一级字段名；关联行缩进展示关联字段名 |
| 类型 | 字段格式标签 |
| 必填 | 是 / 否 |
| 展示条件 | 一级：—；关联：仅展示 `当「一级字段」= 值 时展示`，不附带选项/备注等其它信息 |
| 操作 | 一级：编辑、+关联二级字段（仅单选多选）、上移、下移、删除；二级：编辑、删除 |

## 4. 弹窗

### 4.1 新增 / 编辑模块

模块名称*、排序；【取消】【确定】。

### 4.2 新增 / 编辑一级字段

字段名称*、字段格式*、选项*（单选多选）、是否必填、**所属模块***（可筛选选择，位于是否必填下方；编辑时可改到其他模块）、占位提示、备注。

### 4.3 添加 / 编辑关联字段

| 项 | 说明 |
| --- | --- |
| 标题 | 添加关联字段 / 编辑关联字段 |
| 一级字段 | 只读 |
| 当一级选项等于 | 下拉，选项来自一级字段 |
| 字段名称 / 格式 / 选项 / 必填 | 与新增字段相同 |
| 所属模块 | 展示一级字段所在模块，不可单独修改 |
| 占位 / 备注 | 可选 |
| 校验 | 未选选项值、未填名称、单选多选无选项、未选模块时拦截 |

> 关联行【编辑】即打开本弹窗编辑该关联字段，**不是**改模块勾选。

## 5. 示例（尽调）

| 一级字段 | 当选项等于 | 关联字段示例 |
| --- | --- | --- |
| 白条产品类型 | 预混料 | 每月玉米需求量、预混料商品名称、预混料报价 |
| 白条产品类型 | 全价料 | 全价料每月吨数、全价料商品名字、单价、全价料捆绑商品的吨数 |
| 白条产品类型 | 大宗免息白条 | 每月玉米需求总量、每月豆粕需求总量 |
| 法人是否为实控人 | 否 | 实控人身份证人像面、国徽面、实名手机号 |

## 6. 空态与校验

| 场景 | 表现 |
| --- | --- |
| 无模块 / 无字段 | 空态引导 |
| 非单选多选点关联字段 | 提示仅单选/多选可配 |
| 一级无选项 | 提示先配置选项 |
| 关联未选选项值 / 未填名称 | 拦截提示 |
| 删除 | 二次确认 |
