# 【需求】客户端 · 正式进件资料补充（二期）

> **范围**：仅客户端「正式进件资料补充」填写与提交本页（含 ≥30 万时实控人信息与实控人征信获取）。正式进件审核结果页、银行分流、担保人补充、业务端尽调、Admin 审核等**不在本文**。  
> **原型**：`步骤1_客户初审三步流程_V3.html` → 步骤 2「正式进件资料补充」（`#resupplyFormBox`）；演示入口：顶部【正式进件资料补充】。  
> **入口关联（只读说明）**：初审通过后，客户从消息「请补充正式进件资料」、银行白条进度或等价入口进入；业务员已提交尽调后，系统按尽调结果决定本页展示与校验项，客户只补交经营类资料。  
> **背景**：一期完成初审。二期正式进件：销售先提交白条类型与尽调 → 通知客户 → **客户在本页补交正式进件资料** → 再进金融正式审核。

## 3. 分模块字段

### 3.1 条件上下文（来自尽调，本页不填）

> 下列条件**不作为本页表单字段**交付。取值取自业务员尽调已提交结果（见《业务端申请资料填写》），系统据此判断本页展示与必传项。

| 条件 | 取值（示例） | 对本页的影响 |
| --- | --- | --- |
| 白条额度档位 | ＜30万 / ≥30万 | ≥30 万：展示主体类型、经营场地权属证明、实控人信息；＜30 万：不展示上述块 |
| 养殖类型 | 禽类 / 猪牛羊（可由尽调养殖品种归并） | 猪牛羊：必传防疫类资料 |
| 是否牧场 | 是 / 否 | 是：必传下游乳企合同 |
| 白条产品类型 | 预混料 / 全价料 / 大宗白条 | 仅全价料：展示并校验百行征信；预混料、大宗白条不需要 |

| 字段（本页采集） | 必填 | 规则 |
| --- | --- | --- |
| 主体类型 | 条件 | 仅额度 ≥30 万展示；个人 / 企业；企业时追加财务三表 |

### 3.2 百行征信报告（仅全价料）

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 百行征信报告提交方式 | 条件 | 尽调产品类型=全价料时必选：上传征信 / 已发送邮箱 |
| 上传百行征信报告 | 条件 | 方式=上传征信；支持 PDF、图片 |
| 收件箱提示 | 条件 | 仅方式=已发送邮箱时展示：`收件箱：jinrong@shyuanyao.com`；方式=上传时不展示 |
| 收取状态 | 条件 | 方式=已发送邮箱；系统检测已收到 / 未收到，可【再次查询】；提交前须已收到 |

> 预混料、大宗白条：整块不展示，提交不校验百行。

### 3.3 动态必传资料

> 以下为客户端本页需客户提交的经营类资料（与业务员尽调页字段不同）。清单由 §3.1 尽调条件 + 本页主体类型决定。

| 资料项 | 必传条件 | 交互 / 规则 |
| --- | --- | --- |
| 近1年经营性流水来源 | 始终 | 多选（银行 / 支付宝 / 微信等，可搜索）；提示从银行 APP、微信、支付宝获取并发送至 `jinrong@shyuanyao.com` |
| {来源}流水解压密码 | 每个已选流水来源 | 文本必填 |
| 近3个月经营场地水电费账单 | 始终 | 上传；提示「水电有其一即可」 |
| 最近一次养殖资产买卖合同/首付款凭证 | 始终 | 上传 |
| 经营场地权属证明 | 额度 ≥30 万 | 上传；租赁合同/产权证明/土地证明等 |
| 动物防疫登记证或出栏防疫记录 | 养殖类型=猪牛羊 | 上传 |
| 下游乳企合同 | 是否牧场=是 | 上传 |
| 最近1年和最近1期的财务三表 | 额度 ≥30 万且主体类型=企业 | 上传 |

### 3.4 实控人征信报告（仅额度 ≥30 万）

> 法人是否为实控人、实控人姓名 / 身份证 / 手机号由业务员尽调填写，本页不采集。

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 实控人姓名 | 只读 | 取自业务员尽调 |
| 实控人征信报告 | 是 | **仅上传**；提示「近一个月征信报告」；支持 PDF、图片。无提交方式切换、无「去人行」 |

## 4. 校验摘要（提交）

1. 尽调条件已齐备（额度档位、养殖类型、是否牧场、产品类型）；≥30 万时本页已选主体类型。  
2. 至少选择 1 个流水来源；每个来源的解压密码已填。  
3. 当前清单内全部必传上传位已完成。  
4. 流水邮箱核验通过（未收到则拦截）。  
5. 全价料：百行已上传（PDF/图片）或邮箱已收到；预混料 / 大宗白条跳过。  
6. ≥30 万：实控人征信报告已上传。
