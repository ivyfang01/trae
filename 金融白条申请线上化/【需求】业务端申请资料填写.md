# 【需求】业务端 · 申请资料填写（二期·先行）

> **范围**：仅业务员提交「白条类型 + 尽调/申请资料」本页。客户端正式补件、Admin 正式审核、消息通知等二期其他模块**不在本文**。  
> **原型**：`业务端_申请资料填写.html`  
> **入口关联（只读说明，不展开改列表）**：客户档案「白条档案」→ 业务员申请资料【去补齐】/【修改资料】；白条申请列表/进度在初审通过后进入本页（与现网按钮文案对齐即可）。  
> **背景**：一期已完成客户初审提交、Admin 金融初审与消息。二期正式进件前，须由销售先提交白条类型与尽调资料，客户再按销售填写内容补交资料。

## 2. 页面逻辑

| 页面 | 逻辑 |
| --- | --- |
| **业务员申请资料**<br/><br/>原型：`业务端_申请资料填写.html`<br/><br/>状态：新建填写 / 草稿回填 / 驳回后修改回填 | **1. 入口**<br/>初审已通过（或业务员申请资料被驳回需重提）后，从白条档案「业务员申请资料」或白条申请进度相关入口进入。带客户上下文；客户名称只读。<br/>无该客户权限、初审未通过：不可进，提示并返回。<br/><br/>**2. 页面字段与规则**<br/>见下文 §3 分模块字段表。关键联动：<br/>· 白条产品类型：**预混料 / 全价料 / 大宗免息白条**（取值大宗）。<br/>· 上银额度填 0：展示并必填「不申请上海银行原因」。<br/>· 全价料与预混料均展示上银、锡商额度（万）；占位「请输入，不申请填写0」。<br/>· 客户类型取养殖档案：养殖户 / 次终端 / 饲料厂（可下拉演示切换）。<br/>· 「客户养殖信息」一卡：养殖户才展示「是否是牧场」；次终端/饲料厂展示「客户阶段」（新客户/存量客户），并隐藏：是否牧场、收蛋/鸡粪、养殖相关字段块、预混料绑定及相关字段；预混料时展示「在平台购买次数」（平台统计只读）。<br/>· 预混料：展示收蛋、处理鸡粪；全价料：隐藏收蛋/鸡粪，展示「是否供应商存量客户」。<br/>· 养殖类型：鸡/鸭/鹅/猪/牛/羊。鸡、猪、牛展示经济用途（多选），并按勾选项展开各类「养殖数量」；仅鸡展开各类「日龄」（天）。猪另展示「有无防疫证」。鸭/鹅展示通用养殖数量 + 日龄；羊仅通用养殖数量，无日龄。<br/>· 饲料信息随产品类型切换字段（见 §3.3）。选大宗免息白条时展示大宗饲料字段。<br/>· 经营信息：法人名字取初审只读；法人非实控人时补实控人三要素；有合伙人时默认带出 1 条，可继续添加多条。<br/>· CRM：自动取该客户今日拜访；无记录提示先去 CRM 拜访（提交是否强拦本期可与现网策略对齐，原型有空态提示）。<br/><br/>**3. 操作与跳转**<br/>【返回】（含顶栏 ‹）：无未保存修改则直接返回；有内容修改未保存时弹窗提示「有内容修改未保存，建议保存后再返回。」，按钮【放弃修改】（不保存返回）、【保存修改并返回】（先存草稿再返回）。点遮罩可关闭弹窗继续编辑。<br/>【保存草稿】：存草稿，清除未保存标记，不改工单审核状态。<br/>【提交申请】：校验必填/必传后提交成功；工单进入「待客户按销售资料补正式件」或等价进行中状态（具体状态名与列表对齐时再定）；弹窗提示「尽调资料已提交，请联系客户提交正式进件需要的资料。」，按钮【确认】后返回档案/进度，不再弹未保存提示。<br/>改产品类型、客户类型、养殖类型、经济用途：即时显隐与重算展示块，不清空无关已填项（切换类型导致隐藏的字段可不落库或按实现清空隐藏项）。<br/><br/>**4. 审批流程**<br/>本页无审批。提交后由后续「客户补件 → Admin 正式审核」承接（不在本文）。<br/><br/>**5. 消息通知**<br/>业务员提交尽调资料成功后，通知客户补充正式进件资料（卡片见 `步骤1_消息通知卡片.html` §8）。文案示意：请补充正式进件资料；跳转客户正式补件入口。<br/><br/>**6. 边界与异常**<br/>未登录不可进。网络失败可重试。驳回修改：带回上次提交内容与驳回项（驳回原因展示位置在档案/进度，本页可不重复置顶原因条）。<br/><br/>**7. 数据字段**<br/>见 §3；另含工单 id、客户 id、提交人、提交/保存时间、草稿标记。 |

## 3. 分模块字段

### 3.1 白条申请

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 客户名称 | 是 | 只读，带入；置于白条产品类型之上 |
| 白条产品类型 | 是 | 预混料 / 全价料 / 大宗免息白条 |
| 额度 | 是 | ＜30万 / ≥30万 |
| 上海银行额度 | 是 | 数字，单位万；不申请填 0；为 0 时必填不申请原因 |
| 锡商银行额度 | 是 | 数字，单位万；不申请填 0；各产品类型均展示 |
| 不申请上海银行原因 | 条件 | 上银额度=0 时展示且必填 |
| 申请原因 | 是 | 多行文本 |

### 3.2 客户养殖信息

> 原「客户基础信息」「养殖信息」合并为一卡，字段与联动不变。

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 客户类型 | — | 取养殖档案：养殖户 / 次终端 / 饲料厂 |
| 是否是牧场 | 条件 | 仅养殖户；是/否 |
| 客户阶段 | 条件 | 仅次终端/饲料厂；新客户 / 存量客户 |
| 是否平台合作收蛋客户 | — | 仅非全价料且非次终端/饲料厂；是/否 |
| 是否平台合作处理鸡粪 | — | 同上 |
| 是否供应商存量客户 | — | 仅全价料；是/否 |
| 养殖字段块显隐 | — | 客户类型为次终端/饲料厂时隐藏本卡内养殖相关字段（养殖类型及以下） |
| 养殖类型 | — | 取客户档案枚举：鸡、鸭、鹅、猪、牛、羊（可改选联动） |
| 经济用途 | 条件 | 鸡：蛋鸡/肉鸡/青年鸡/育雏鸡（多选）；猪：繁殖/育肥/仔猪/保育猪（多选）；牛：奶牛/肉牛/青年牛（多选） |
| {用途}养殖数量 | 条件 | 每个已选经济用途一项；鸡单位羽/头/只，猪牛单位头 |
| {用途}日龄 | 条件 | 仅鸡；单位天 |
| 养殖数量（通用） | — | 鸭/鹅/羊等无经济用途明细时展示；取客户档案可改；单位羽/头/只 |
| 日龄（通用） | — | 仅鸭/鹅；单位天；猪/牛/羊不展示 |
| 有无防疫证 | 条件 | 仅猪；有/无 |

### 3.3 饲料信息

**预混料**

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 在平台购买次数 | — | 仅次终端/饲料厂；平台统计只读 |
| 每月玉米需求量 | 是 | 吨 |
| 每月豆粕需求量 | 是 | 吨 |
| 预混料需求量 | 是 | 吨 |
| 是否绑定销售预混料 | 条件 | 非次终端/饲料厂；是/否 |
| 预混料每月吨数 / 商品名称 / 报价 | 条件 | 绑定=是；报价单位元/吨 |
| 不能绑定预混料的原因 | 条件 | 绑定=否 |

**全价料**

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 全价料每月吨数 | 是 | 吨 |
| 全价料厂家名字 | 是 | 文本 |
| 单价 | 是 | 元/吨 |

**大宗免息白条**

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 新/存量客户 | — | 系统取值，只读（客户类型沿用上方「客户养殖信息」，不重复展示） |
| 平台购买次数 | — | 平台统计，只读 |
| 每月玉米需求总量 | 是 | 吨 |
| 每月豆粕需求总量 | 是 | 吨 |

### 3.4 经营信息

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 法人名字 | — | 取初审资料，只读 |
| 法人是否为实控人 | 是 | 是/否；否则展开实控人姓名、身份证号、手机号（均必填） |
| 实控人从业年限 | 是 | 不满1年 / 1-2年 / 2-5年 / 5年以上 |
| 是否有合伙人 | 是 | 选「是」默认展示 1 组姓名+手机号（无需点添加）；多条时点【＋继续添加合伙人】；仅 1 条时不可删，多于 1 条可删但仍至少保留 1 条 |
| 实控人家庭住址 | 是 | 文本 |
| 实控人资产情况 | 是 | 多选：商品房、汽车、自建房、股票期权等 |
| 实控人车牌号 | 否 | 文本 |
| 经营场所属性 | 是 | 完全租赁 / 合伙租赁 / 自有 |
| 年租金 | 是 | 单位万元；自有场所填 0 |
| 经营场所规模 | 是 | 单位㎡ |
| 向上下游打听口碑 | 是 | 良好 / 存在负面评价 / 无法获取 |
| 向周边及员工打听口碑 | 是 | 同上 |
| 平均出货频率 | 是 | 每日 / 每3至7天 / 每15日至1个月 / 1个月以上 / 不固定 |
| 下游结算形式 | 是 | 现金 / 微信 / 支付宝 / 公户转账 / 个人银行卡 |

### 3.5 现场照片或视频

| --- | --- | --- |

### 3.6 CRM 拜访记录

| 字段 | 规则 |
| --- | --- |
| 标题旁说明 | 「自动取今日拜访」 |
| 有拜访 | 展示今日拜访摘要 +【查看详情】跳转已有 CRM 拜访详情 |
| 无拜访 | 提示：今日暂无该客户拜访记录，请先在 CRM 完成今日拜访后再提交 |

## 4. 校验摘要（提交）

1. 白条产品类型、额度、上银/锡商额度、申请原因。  
2. 上银=0 时不申请原因。  
3. 养殖户：是否牧场；养殖信息与经济用途明细按类型必填。  
4. 次终端/饲料厂：客户阶段。  
5. 饲料信息按产品类型必填项。  
6. 现场照片/视频至少 1 项。  
7. 经营信息必填项；法人非实控人时实控人三要素；有合伙人时各组姓名与手机号。  
8. CRM 强校验是否拦截：与业务确认（原型已有空态文案）。
