# 【需求】Admin · 金融白条审核台 · 查看页

> **范围**：仅 Admin「金融白条审核台」详情的 **查看模式**（只读全貌）。列表筛选/Tab、编辑模式、初审/正式审核操作、推送银行动作、平台审核拒绝等**不在本文**（见《【需求】Admin金融白条审核台》）。  
> **原型**：`步骤1_金融初审审核.html` → `#detailPage`（`openTask(id,'view')`，加 `view-mode`）  
> **入口**：列表行【查看】；任意平台审核状态下均可进。  
> **背景**：金融人员只读查阅进件全貌（状态、资料齐全度、档案、附件、尽调、正式件、征信交易、银行推送与日志），不在本页改状态、不审批、不发消息。

## 3. 分模块字段

### 3.1 审核状态

| 展示 | 规则 |
| --- | --- |
| 平台审核状态 | 标签；展示名：初审草稿 / 初审审核中 / 初审驳回 / 正式进件草稿 / 正式进件审核中 / 正式进件审核通过 / 正式进件审核驳回 |
| 银行状态 | 标签；展示名：— / 银行审批中 / 白条已开通 / 银行拒绝 |
| 驳回原因 | 仅平台态=初审驳回或正式进件审核驳回且有原因时附文案 |
| 银行拒绝原因 | 仅银行状态=银行拒绝且有原因时附文案 |

### 3.2 资料与 AI 识别

| 展示 | 规则 |

### 3.5 附件（三区）

> 面板标题「附件」；标题右侧提供【全部下载】（打包下载当前工单三区内全部**已上传**附件；无已上传项时提示）。单项已上传可预览/下载（原型 alert）；未上传灰色占位。

| 分区 | 附件项 | 规则 |
| --- | --- | --- |
| 初审附件 | 营业执照、法人身份证正面、法人身份证反面、信用分截图、法人征信报告 | 来自客户初审 |
| 业务员尽调资料附件 | 实控人身份证正面、实控人身份证反面；现场照片/视频 | **仅**尽调「法人是否为实控人=否」时展示实控人身份证正反面；无尽调时提示尚未提交 |
| 客户正式补件附件 | 经营性流水；百行征信报告（条件）；实控人征信报告（条件）；其他正式件（水电、合同、权属、财务三表等） | 百行：产品=全价料时展示；实控人征信：额度 ≥30 万时展示。无正式件：初审未过提示「初审通过后方可…」，否则「客户尚未提交…」 |

### 3.6 业务员尽调资料

> 有数据时副标题「状态：{已提交/未提交}」；面板标题右侧【下载尽调资料】导出 Excel（模块/字段/内容）。数据来源见《【需求】业务端申请资料填写》。

| 子区 | 字段 |
| --- | --- |
| 空态 | 初审未过：「初审通过后业务员方可提交尽调资料」；已过初审未提交：「业务员尚未提交申请资料」 |
| 白条申请 | 白条产品类型；预混料/全价料时展示是否能收取保证金；申请额度（万）；上海银行额度（万）；上银额度＞0 时展示上银免息期（天）、是否开通自动支付、最长借款期（月）；锡商银行额度（万）；锡商额度＞0 时展示锡商免息期（天）、最长借款期限（月）；上银额度=0 时展示「不申请上海银行原因」；申请原因（多行） |
| 客户养殖信息 | 养殖种类、养殖数量、从事行业年限 + 尽调模板养殖相关字段 |
| 饲料信息 | 随产品类型的模板字段；无则 — |
| 经营信息 | **法人是否为实控人**；=否时展示 **实控人姓名 / 实控人身份证号 / 实控人手机号**；其余从业年限、住址、资产、车牌、是否有合伙人及合伙人信息、经营场所、口碑、出货频率、结算形式等 |
| CRM 拜访记录 | 摘要只读 +【查看详情】（跳转 CRM，实现不在本文） |

> 实控人三要素仅在本模块展示，不在「客户正式进件资料」表单区重复。

## 5. 边界与异常

1. 未登录 / 无金融审核权限：不可进入。  
2. 工单不存在或已删除：提示后回列表。  
3. 附件预览失败：提示重试。  
4. CRM【查看详情】跳转失败：提示稍后重试，不阻断本页。  
5. 条件模块隐藏时不占位、不展示空壳标题。
