## 1. 背景与目标

自提订单常由客户自行安排车辆提货，需补录 **车牌号**，并上传 **运费付款凭证**，便于税务部门核查业务真实性。

**目标：**

1. 或者车牌号和付款凭证
2. 截图中可查询该订单的付款凭证和车牌号码

## 3. 适用范围与状态（需确认后开发）

### 3.1 订单过滤条件（同时满足）

- 品类 = 鸡蛋  
- 提货方式 = 买家自提

### 3.2 可操作状态（建议，待业务拍板）


| 状态  | 上传 / 重传凭证入口 | 录入 / 修改车牌 | 说明  |
| --- | ----------- | --------- | --- |
| 待确认 | 否           | 展示修改入口    |     |
| 待出库 | **展示上传入口**  | 展示修改入口    |     |
| 发货中 | **展示上传入口**  | 展示修改入口    |     |
| 已完成 | **展示上传入口**  | 展示修改入口    |     |
| 已取消 | 否           | 否         |     |


> 原文「在什么状态」未填清。上表为建议默认：**待出库、发货中、已完成** 可操作；若已完成只读，开发前请业务确认并改表。



## 4. 功能说明



### 4.1 订单列表（鸡蛋 · 自提）

**入口位置：** 订单卡片操作区（与「转发」等并列）。


| 凭证状态 | 按钮文案   | 点击行为              |
| ---- | ------ | ----------------- |
| 未上传  | 上传运费凭证 | 打开上传面板，选图 / 拍照后提交 |
| 已上传  | 重新上传   | 同上；成功后覆盖原图        |


**规则：**

- 非自提订单不展示该按钮  
- 不在可操作状态不展示
- 上传成功 Toast：`运费凭证上传成功`  
- 列表可不展示缩略图（详情查看即可）



### 4.2 订单详情（自提）



#### 4.2.1 运费付款凭证


| 状态  | 展示                       | 操作                     |
| --- | ------------------------ | ---------------------- |
| 未上传 | 文案「未上传」                  | 「上传凭证」；可选底部主按钮「上传运费凭证」 |
| 已上传 | **直接展示缩略图**（不展示「已上传」状态字） | 点图放大；「重新上传」覆盖          |


**交互细节：**

- 放大：全屏 / 预览层，支持关闭  
- 重新上传成功后刷新缩略图  
- 字段建议放在「运费总价」附近（价格信息区）
- 支持 JPG / JPEG / PNG，单张不超过 5MB。 每个订单仅 1 张，重新上传将覆盖原凭证，相册和拍照都可以



#### 4.2.2 车牌号


| 状态  | 展示               | 操作             |
| --- | ---------------- | -------------- |
| 未填写 | 「请填写车牌号」或空 +「填写」 | 弹层 / 行内输入，确认保存 |
| 已填写 | 展示车牌号明文          | 「修改」后保存        |


**校验建议：**


| 项    | 规则                                      |
| ---- | --------------------------------------- |
| 必填时机 | 【待确认】上传凭证前是否强制先填车牌；建议「车牌与凭证相互独立，均可单独保存」 |
| 格式   | 支持新能源车牌；字母数字；去除首尾空格；统一大写字母              |
| 长度   | 建议 7～8 位（含省份简称）；不通过提示：`请输入正确的车牌号`       |


**展示位置：** 物流信息区（提货方式、司机信息附近）；自提无司机时仍展示车牌字段。

### 4.3 Admin 后台 · 订单详情


| 字段     | 未上传 / 未填 | 已有数据 | 操作                    |
| ------ | -------- | ---- | --------------------- |
| 运费付款凭证 | 文案「未上传」  | 缩略图  | 点击看大图；本期 **不支持** 后台代传 |
| 车牌号    | 「—」或空    | 明文展示 | 本期只读                  |
