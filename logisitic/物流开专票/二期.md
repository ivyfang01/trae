# 物流开专票 · 二期

## UI 色板（参考粮巴巴合同/订单截图）

| Token | 色值 | 用途 |
|-------|------|------|
| `--brand` | `#FF6B00` | 主按钮、状态强调、选中态、电话图标 |
| `--brand-grad` | `linear-gradient(90deg, #FF6B00 0%, #FFB347 100%)` | 状态头（如待付保证金） |
| `--link` | `#1E88E5` | 链接、次要操作按钮描边/文字、标签「计划提货」 |
| `--bg` | `#F5F5F5` | 页面底色 |
| `--card` | `#FFFFFF` | 信息卡片 |
| `--text` | `#333333` | 主标题、重要数值 |
| `--label` | `#666666` | 左侧标签文案 |
| `--muted` | `#999999` | 次要说明、占位 |
| `--line` | `#EEEEEE` | 分割线 |
| `--tag-bg` | `#FFF3E8` | 浅橙标签底 |
| `--tag-text` | `#FF6B00` | 浅橙标签字 |
| `--danger` | `#FF4D4F` | 取消/失败（少用） |

**布局约定：** 白卡片分区；左标签右数值；主操作底部固定橙按钮（圆角 8px 或胶囊）；列表卡片底部分组按钮：蓝=次要、橙=主路径。

## 页面清单

### 页面1：下单物流订单
- 类型：表单
- 字段：货物名称、吨数、装货地、卸货地、配送日期、运费（按运费模板计算）、运输协议勾选
- 操作：确认下单
- 原型：`demo/01-create-order.html`

### 页面2：支付
- 原型：`demo/02-pay.html`

### 页面3：物流订单列表
- 操作：付款、查看详情、取消订单
- 原型：`demo/03-order-list.html`

### 页面4：物流订单详情
- 操作：付款、取消订单（详情内以底部主操作为主）
- 原型：`demo/04-order-detail.html`
