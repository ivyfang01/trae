# MRD · 鸡蛋物流轨迹和装卸货时差提醒

> 日期：2026-09-08  
> 状态：出原型 + PRD

## 需求描述



鸡蛋物流订单，需要做如下需求：

1. **开始接单** 和 **开始卸货** 时间差 ≤15 分钟 → 提醒派单员
2. **开始装货** 后，满 **12 小时** 仍未点击开始卸货 → 消息提醒派单员
3. 支持在 **钉钉后台** 和 **Admin 后台** 点击【开始卸货】；经纬度直接取值卸货地址的经纬度，或可不取经纬度

## 说明

- 提醒接收人：该单派单员（钉钉工作通知 @）  
- 后台代点开始卸货：弹窗选择「使用卸货地址经纬度」或「不取经纬度」；记录操作端与操作人  
- 细则与待确认项见 PRD 第 8、13 节
