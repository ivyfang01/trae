## 1. 产品概述

### 1.1 一句话定位
为鸡蛋物流派单员提供装卸履约时差异常提醒，并支持在钉钉后台 / Admin 代点「开始卸货」。

### 1.2 核心价值主张
及时发现「接单→卸货过短」与「装货后长期未卸货」两类异常，降低虚假履约与滞留风险；在司机未操作时可由后台补录卸货节点，保证轨迹链路完整。

---

## 2. 背景与目标

### 2.1 业务背景
- **现状**：鸡蛋物流依赖司机端节点（开始接单 / 装货 / 卸货）；派单员缺少时差异常主动触达，后台也缺少代点「开始卸货」能力。
- **痛点**：短时差可能误点或虚假履约；装货后长时间未开始卸货难以及时跟进。
- **机会**：按规则钉钉提醒该单派单员；并在 Admin / 钉钉物流详情支持代操作开始卸货（经纬度取卸货地址或不取）。

### 2.2 产品目标
- **O**：提升鸡蛋物流装卸节点真实性与异常响应速度。
  - **KR1**：[建议值，待确认] 规则命中后钉钉触达成功率 ≥ X%。
  - **KR2**：[建议值，待确认] 「装货后超 12h 未卸货」提醒后 24h 内完成卸货节点占比 ≥ Y%。
  - **KR3**：[建议值，待确认] 后台代点开始卸货可观测（操作人 / 来源端 / 经纬度策略）。

### 2.3 成功指标
- **北极星指标**：异常提醒后到「开始卸货」闭环时长（中位数 / P90）。
- **辅助指标**：15 分钟规则触发量；12 小时规则触发量；后台代点占比；钉钉点击「查看物流单」率。

## 7. 用户流程

### 7.1 核心流程

#### Flow-1：接单→卸货过短提醒
**模块**：M-1｜**功能**：F-1

| 步骤 | 触发 / 操作 | 系统响应 |
|------|------------|---------|
| 1 | 写入「开始卸货」时间 | 计算 `开始卸货 − 开始接单` |
| 2 | 间隔 ≤ 15 分钟 | 钉钉通知该单派单员（卡片场景「过短」） |
| 3 | 派单员点「查看物流单」 | 打开对应详情核实 |

#### Flow-2：装货后超时未卸货提醒
**模块**：M-1｜**功能**：F-2

| 步骤 | 触发 / 操作 | 系统响应 |
|------|------------|---------|
| 1 | 已有「开始装货」，且尚无「开始卸货」 | 自装货时间起计时 |
| 2 | 满 12 小时仍无开始卸货 | 钉钉通知派单员（卡片场景「超时」） |
| 3 | 派单员跟进；可代点开始卸货 | 见 Flow-3 |

#### Flow-3：后台代点开始卸货
**模块**：M-2｜**功能**：F-3 / F-4

| 步骤 | 操作 | 系统响应 |
|------|------|---------|
| 1 | 在 Admin 或钉钉详情点【开始卸货】 | 弹出确认与经纬度策略 |
| 2 | 选「使用卸货地址经纬度」或「不取经纬度」并确认 | 写入开始卸货节点；记录操作端 / 操作人 |
| 3 | 已开始卸货 | 按钮置灰；F-2 不再对该单触发（已卸货） |

### 7.2 状态 / 节点流转

```
开始接单 → 开始装货 → 开始卸货 → …（后续既有节点）
                ↑
         也可由 Admin / 钉钉代写「开始卸货」
```

### 7.3 异常路径

| 场景 | 处理 |
|------|------|
| 钉钉发送失败 | 日志 + 重试；派单员仍可在列表/详情查看 |
| 无派单员 / 派单员未绑定钉钉 | 记录失败原因；待确认兜底接收人 |
| 卸货地址无经纬度却选「取地址经纬度」 | 提示不可用，引导改选「不取」或先补地址经纬度（待确认） |
| 已存在开始卸货再点 | 按钮不可用 / 幂等拒绝 |
| 同单同规则重复触发 | MVP 建议每规则每单限频 1 次 |

## 8. 功能详细设计

### M-1：时差异常通知

#### F-1：接单→卸货 ≤15 分钟提醒
- **描述**：鸡蛋物流单在写入「开始卸货」后，若与「开始接单」时间差 ≤ 15 分钟，即时提醒派单员。
- **来源**：JTBD-1
- **原型**：`钉钉卡片-装卸时差提醒派单员.html`（场景：接单→卸货 ≤15分钟）
- **触发条件**：
  1. 品类 = 鸡蛋物流订单
  2. 已存在开始接单、开始卸货时间
  3. `开始卸货时间 − 开始接单时间 ≤ 15 分钟`（含等于）
- **卡片字段**：物流单号、司机、装/卸货地址、开始接单时间、开始卸货时间、时差、提醒原因；按钮【查看物流单】
- **接收人**：该单派单员（@）
- **限频**：同单一规则建议仅提醒 1 次

#### F-2：装货后 12 小时未开始卸货提醒
- **描述**：开始装货满 12 小时仍未点击开始卸货，提醒派单员跟进。
- **来源**：JTBD-2
- **原型**：同上（场景：装货后超12小时未卸货）
- **触发条件**：
  1. 品类 = 鸡蛋物流订单
  2. 已有开始装货时间
  3. 当前仍无开始卸货节点
  4. `当前时间 − 开始装货时间 ≥ 12 小时`
- **实现建议**：定时任务扫描（如每 5～10 分钟）或装货时注册延迟任务；以落地技术选型为准
- **限频**：同单一规则建议仅提醒 1 次；一旦写入开始卸货则取消待发任务

### M-2：后台开始卸货

#### F-3：Admin 代点开始卸货
- **描述**：Admin 鸡蛋物流单详情提供【开始卸货】；确认时可选择经纬度策略。
- **来源**：JTBD-3
- **原型**：`Admin-鸡蛋物流单详情-开始卸货.html`
- **交互**：
  1. 未开始卸货时展示主按钮【开始卸货】
  2. 弹窗二选一：
     - 使用卸货地址经纬度
     - 不取经纬度（经纬度留空）
  3. 确认后写入节点：时间 = 操作时刻；操作端 = Admin；操作人 = 当前登录用户
- **展示**：履约节点表增加「开始卸货」行；状态文案更新为已开始卸货类

#### F-4：钉钉后台代点开始卸货
- **描述**：钉钉侧物流详情与 Admin 同等能力与字段规则。
- **来源**：JTBD-3
- **原型**：`钉钉-鸡蛋物流详情-开始卸货.html`
- **差异**：移动端底部操作栏 + 底部确认面板；其余业务规则同 F-3
