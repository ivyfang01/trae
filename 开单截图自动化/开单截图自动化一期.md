# **<font style="color:rgb(0, 0, 0);">1.背景</font>**
**<font style="color:rgb(15, 17, 21);">当前痛点：</font>**

+ <font style="color:rgb(15, 17, 21);">客户在企微群中发送开单截图后，运营需要手动识别截图内容，并转发到钉钉群，给到客服转发给客户，人工查找对应对应订单信息效率低下，响应延迟，客户无法及时活得订单状态反馈。</font>

**<font style="color:rgb(15, 17, 21);">业务价值：</font>**

+ <font style="color:rgb(15, 17, 21);">提升客户服务响应速度和质量</font>
+ <font style="color:rgb(15, 17, 21);">减少人工操作成本，提高工作效率</font>
+ <font style="color:rgb(15, 17, 21);">标准化订单信息处理流程</font>



### <font style="color:rgb(15, 17, 21);">2. 项目目标</font>
**<font style="color:rgb(15, 17, 21);">主要目标：</font>**

+ <font style="color:rgb(15, 17, 21);">实现开单截图的自动识别与处理</font>
+ <font style="color:rgb(15, 17, 21);">建立截图内容与系统订单的智能关联</font>
+ <font style="color:rgb(15, 17, 21);">自动化向客户发送确认和状态消息</font>

**<font style="color:rgb(15, 17, 21);">可衡量指标：</font>**

+ <font style="color:rgb(15, 17, 21);">截图识别准确率：≥80%</font>
+ <font style="color:rgb(15, 17, 21);">订单关联准确率：≥80%</font>
+ <font style="color:rgb(15, 17, 21);">消息自动发送成功率：≥80%</font>
+ <font style="color:rgb(15, 17, 21);">人工干预率：≤20%</font>
